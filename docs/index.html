02 / SAFETY GATE

Before anything is written

Keep the evidence. Remove the credential.

The intake boundary sanitizes the subject, description and request ID before SQLite receives them. Operators still get the time, impact and correlation context needed to investigate.

The safest secret in an incident record is the one that was never stored.

What this proves—and what it does not.

It demonstrates safe evidence handling, deterministic urgency, explicit ownership and auditable handoff. A production deployment still needs authentication, tenant isolation, stronger PII detection, encryption, retention policy, idempotency and operational observability.
